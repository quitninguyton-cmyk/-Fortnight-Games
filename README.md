# ⚡ BattleZone — Battle Royale Challenge Hub

🎮 **BattleZone** is a fan-made, browser-based Battle Royale challenge game.

Complete challenges, earn XP, level up, collect coins, unlock cosmetics, choose your drop location, and compete for the top of the leaderboard!

---

## 🎮 Features

- 🚌 Simulated Battle Royale matches
- 💀 Random eliminations
- 🏆 Random victories
- ⭐ XP and leveling system
- 🪙 Coin currency
- 🎯 Daily challenges
- 🗺️ Interactive Battle Map
- 🛒 Item Shop
- 🎒 Player Inventory
- 🏅 Achievements
- 🎁 Daily rewards
- 🏆 Leaderboard
- 💾 Automatic browser save system
- 📱 Mobile-friendly design
- 💬 Discord community button

---

## 💾 Save System

Your progress is saved automatically in your browser using `localStorage`.

Your saved information includes:

- Level
- XP
- Coins
- Wins
- Eliminations
- Matches
- Completed challenges
- Inventory
- Achievements
- Daily reward status
